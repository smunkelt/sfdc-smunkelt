sfdcsm_DynamicRelatedList

Dynamic related-list component for lightning__ServiceDocument, powered by sfdcsm_DBDynamicRelatedListController.

Component Functionality (Summary)

  • Renders a configurable related list in Service Document templates.
  • Supports dynamic relationship linkage using current record Id or a configurable source path.
  • Allows dynamic column selection, custom labels, and per-column text alignment.
  • Supports sorting and optional filter criteria to constrain displayed rows.
  • Formats Date, Time, and DateTime values according to user locale/timezone settings.
  • Includes configurable title sizing and optional display when no rows are returned.
  • Provides built-in loading, empty-state, and error-state handling.

Main Features

1) Flexible Data Linkage

The related-record query can link directly by current record Id, or by a field path on the source record. This enables scenarios like starting from ServiceAppointment and linking via SFS_WorkOrder__c.

2) Dynamic Datatable Definition

Columns, labels, and alignment are configured in template design properties instead of hardcoding. Relationship columns (for example Asset.Product2.Name) are supported.

3) Query Controls

Sorting and filtering can be configured to match a document section use case, such as showing only records in a specific status.

4) Locale-Aware Value Formatting

Date, Time, and DateTime values are normalized and rendered for user locale/timezone readability. Time values that arrive as milliseconds are converted to user-friendly time output.

Design Settings - Detailed Reference

Setting Purpose Example
relatedEntityDefinition Defines target object + lookup field used to link related records. Format: ChildObjectApiName:LookupFieldApiName. WorkOrderLineItem:WorkOrderId Query WorkOrderLineItem records where WorkOrderId = linkage value.
sourceLinkFieldPath Optional field path on the current record used as linkage value. If blank, current recordId is used. SFS_WorkOrder__c On ServiceAppointment, link related records through the Work Order Id.
relatedListTitle Header text shown above the datatable. Installed Assets Displays "Installed Assets" as section title.
titleSize Controls title text size. Allowed values: standard, small, medium, large. standard Uses default style intended to align with native related-list look.
showWhenEmpty When checked, the component still renders title + empty-state message if no records are returned. Default is unchecked/false. true Always show the section, even with zero matching rows.
columnsToDisplay Comma-separated field paths used as datatable columns. Supports relationship paths. LineItemNumber,Asset.Name,Asset.SerialNumber,Status Displays a mixed set of direct and related fields.
columnLabels Optional comma-separated labels matching column order. If omitted, labels are derived from field names. Line #,Asset,Serial,Current Status Overrides default labels with business-friendly text.
columnAlignments Optional comma-separated alignments per column: left, center, right. left,left,right,center Aligns each column independently.
sortField Field path used in ORDER BY clause. LineItemNumber Sort records by line item sequence.
sortOrder Sort direction for sortField. Allowed values: ASC, DESC. ASC Shows oldest/smallest value first.
filterCriteria Extra WHERE clause fragment appended to base linkage filter. Do not include the WHERE keyword. Status = 'New' AND IsDeleted = false Only includes active records with status New.

Complete Example Configuration

Example for a ServiceAppointment template that shows WorkOrderLineItems for the parent Work Order:

  • relatedEntityDefinition = WorkOrderLineItem:WorkOrderId
  • sourceLinkFieldPath = SFS_WorkOrder__c
  • relatedListTitle = Work Order Line Items
  • titleSize = standard
  • showWhenEmpty = false
  • columnsToDisplay = LineItemNumber,Asset.Name,Asset.SerialNumber,Status
  • columnLabels = Line #,Asset,Serial Number,Status
  • columnAlignments = left,left,left,center
  • sortField = LineItemNumber
  • sortOrder = ASC
  • filterCriteria = Status != 'Canceled'
