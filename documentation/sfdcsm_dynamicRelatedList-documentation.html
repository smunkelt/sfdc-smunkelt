sfdcsm_DynamicRelatedList

Lightning Web Component — Technical Reference
API Version 66.0  ·  Author: sfdcsm  ·  Last updated: July 2026

1. Overview

sfdcsm_DynamicRelatedList is a configurable Lightning Web Component that renders related records for Service Document templates using a metadata-driven relationship definition. It supports optional source linkage from the current record, dynamic columns, sorting, and filter criteria.

The component uses a generic Apex query layer and a configurable datatable definition so one implementation can support many related-list scenarios without hardcoded object-specific logic.

Key Features

  • Configurable linkage via current recordId or custom source-link field path
  • Dynamic column rendering with optional custom labels and per-column alignments
  • Sort and filter controls to tailor data shown in generated documents
  • Built-in loading, empty-state, and error-state rendering
  • Locale-aware formatting for Date, Time, and DateTime values

3. Design Settings

SettingPurposeExample
relatedEntityDefinition Target object and lookup field in format ChildObjectApiName:LookupFieldApiName. WorkOrderLineItem:WorkOrderId
sourceLinkFieldPath Optional linkage field path on the source record. If blank, component uses recordId. SFS_WorkOrder__c
relatedListTitle Header text displayed above the datatable. Work Order Line Items
titleSize Title size enum: standard, small, medium, large. standard
showWhenEmpty When true, renders title and empty-state message even when no rows are returned. true
columnsToDisplay Comma-separated column field paths, including relationship paths. LineItemNumber,Asset.Name,Status
columnLabels Optional comma-separated labels matching the same order as columns. Line #,Asset,Status
columnAlignments Optional comma-separated alignments: left, center, right. left,left,center
sortField Field path used in ORDER BY clause. LineItemNumber
sortOrder Sort direction for sortField: ASC or DESC. ASC
filterCriteria Additional WHERE fragment (do not include WHERE keyword). Status != 'Canceled'

5. Technical Notes

The Apex controller validates field paths and filter syntax before running dynamic SOQL. It also resolves nested source-link field paths to support multi-hop linkage scenarios.

Response rows are serialized as key/value maps with stable column keys (col_0, col_1, etc.), and the LWC applies client-side value formatting for dates and times based on locale and timezone.

Filter safety: filterCriteria is constrained by character and keyword checks. Unsupported patterns (for example semicolons, SQL comments, or nested SELECT fragments) are rejected.
