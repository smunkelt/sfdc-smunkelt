sfdcsm_actionBanner
A configurable, full-width banner panel for Lightning pages. Displays a coloured bar with an optional SLDS icon, up to two text lines (with merge token support), and up to two action buttons that can invoke an autolaunched Flow.
Targets: Record Page · App Page · Home Page · Screen Flow
 →
sfdcsm_filteredPicklist
A reusable picklist component that restricts available values to those permitted for a specific record type. Flow-ready: fires FlowAttributeChangeEvent, exposes a value output variable, and implements validate().
Targets: Screen Flow · Lightning Record Page
 →
sfdcsm_DynamicRelatedList
A configurable related-list component for Service Document templates that renders records dynamically using relationship definition, source-link field path, configurable columns, sorting, and filter criteria, with locale-aware Date/Time formatting.
Targets: Service Document
